Web Technologies

HTML

HTML stands for HyperText MarkUp Language and is the standard markup language for creating web pages. It uses structured tags to organize elements like text, images, and links on a browser.

CSS

CSS, or Cascading Style Sheets, is one of the core technologies of web development used to control the visual layout and design of webpages. It works alongside HTML and JavaScript to determine colors, fonts, spacing, and overall positioning.

JavaScript

JavaScript is one of the three core technologies used to build modern websites, working alongside HTML and CSS. It adds interactivity and dynamic behaviors, allowing developers to create features like animated graphics and interactive forms.
